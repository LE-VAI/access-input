Access input

The same interface, driven by whatever signal a person has. Pick a mode below and use the surface — rest to activate, or press to scan. The point is that nothing above this layer needs to know which one you used.

Input mode

activations 0 · undos 0 · abandons 0 · dwell 600ms

Rest the pointer on a word until the amber fill completes.

Feedback and calibration

Off until you turn it on. Reads each target aloud once it has focus: after lock-on when dwelling (a passing glance stays silent), on every step when scanning.

Stores only the dwell duration, in this browser, and nothing is sent anywhere. Turning it off deletes it; Reset calibration deletes it and returns to 600ms.

Reading surface

Reading while listening helps because the eye and the ear reinforce each other. The words stay visible while the voice moves through them.
